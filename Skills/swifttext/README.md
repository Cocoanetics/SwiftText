# SwiftText Skill

Agent skill for the [SwiftText](https://github.com/Cocoanetics/SwiftText) CLI:
read PDFs, scans, Word, Pages, Numbers, Keynote and web pages, and render
Markdown into PDF, DOCX, Pages, EPUB or HTML.

- **[SKILL.md](SKILL.md)**: what it reads and writes, rules, common jobs
- **[references/reading.md](references/reading.md)**: the readers in depth
- **[references/writing.md](references/writing.md)**: `render` and `pdf` in depth

Install the CLI with `brew install cocoanetics/tap/swifttext`, and the skill with
`clawhub install swifttext`. The skill ships with every SwiftText release and
carries SwiftText's version.
